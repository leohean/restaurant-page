# Restaurant Page 🍽️

Projeto de uma página de restaurante feita com **HTML**, **CSS** e **JavaScript**, utilizando as bibliotecas **jQuery** e **ScrollReveal**. A proposta é simular uma SPA (Single Page Application) simples, com navegação dinâmica e animações leves.

## 🔍 Funcionalidades

- Navegação dinâmica entre:
  - Home
  - Menu
  - Contato
- Manipulação de conteúdo com jQuery
- Animações de entrada com [ScrollReveal](https://scrollrevealjs.org/)
- Estilização com CSS puro

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- [jQuery](https://jquery.com/)
- [ScrollReveal](https://scrollrevealjs.org/)

## 📁 Estrutura

```plaintext
restaurant-page/
├── index.html       # Página principal
├── style.css        # Estilo da aplicação
├── home.js          # Conteúdo da Home
├── menu.js          # Conteúdo do Menu
├── contact.js       # Conteúdo de Contato
├── index.js         # Script principal (navegação e animações)
```
